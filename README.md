# Brown Books Foundation — website

Static site for Brown Books Foundation, a non-profit for sustainability and learning. We collect old books and donate them to students who need them.

## Files

| Path | What it is |
|---|---|
| `index.html` | The whole site: hero, mission, donation steps, live feed, contact |
| `styles.css` | Styles. Brand colours, responsive layout, reduced-motion support |
| `app.js` | Scroll reveal and the live feed (reads `posts.json`) |
| `assets/logo.jpg` | Brand logo (also the Facebook profile picture) |
| `posts.json` | Recent Facebook posts, generated by `export_feed.py` |
| `export_feed.py` | Pulls recent posts from the Facebook Graph API into `posts.json` |

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Refresh the feed

The page token stays on the server. Nothing in the browser calls Facebook.

```bash
export BBF_PAGE_ACCESS_TOKEN=...   # or keep it in .env
export BBF_PAGE_ID=1798955826801396
python3 export_feed.py
```

Run it on a schedule (cron) or before each deploy. `posts.json` is then served as a static file.

## Deploy

Static hosting works: GitHub Pages, Netlify, Cloudflare Pages, or any web server. No build step.

## Notes

- Keep the page token out of the repo. `export_feed.py` reads it from the environment or a local `.env`.
- The About text, logo, and donation contact must match the Facebook page.
